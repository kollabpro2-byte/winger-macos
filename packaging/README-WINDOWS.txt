Winger VPN для Windows
======================

Это десктопная сборка того же клиента, что и на Android: тот же интерфейс,
те же три темы, тот же вход по логину и та же подписка.

Как запустить
-------------
1. Распакуйте архив в любую папку (например, C:\WingerVPN).
2. Запустите WingerVPN.exe.
   Windows спросит разрешение администратора — оно нужно, чтобы ядро могло
   создать виртуальный сетевой адаптер (VPN на весь трафик).
3. Войдите тем же логином и паролем, что в приложении на телефоне.

Другие способы запуска
----------------------
run-no-admin.bat — без прав администратора. Ядро поднимает локальный прокси
                   127.0.0.1:2080 вместо виртуального адаптера: системный
                   трафик не заворачивается, но можно проверить работу.
run-console.bat  — то же, что exe, но с окном консоли: там видны ошибки
                   Java и ядра, если что-то не запускается.

Если антивирус заблокировал WingerVPN.exe — используйте run.bat: он делает то
же самое через javaw.exe из комплекта.

Что внутри
----------
WingerVPN.exe  лаунчер (32-битный стаб Launch4j, запускает 64-битный JRE)
lib\           jar приложения и библиотеки
jre\           Java 21 (Eclipse Temurin) — ставить Java отдельно не нужно
core\          ядро sing-box-lx 1.14.4 (то же, что в Android-сборке) + wintun.dll

Где лежат настройки и лог
-------------------------
%APPDATA%\WingerVPN
  settings.json  настройки
  secrets.bin    сессия и пароль (AES-GCM, ключ в key.bin)
  vpn.log        журнал (виден в «Настройки → ЛОГ»)
  singbox.log    подробный лог ядра
  core.json      конфиг ядра текущей сессии

Если что-то не работает
-----------------------
1. Запустите run-console.bat и посмотрите вывод.
2. Откройте «Настройки → ЛОГ» и нажмите «Скопировать».
3. Проверьте, что антивирус не удалил core\sing-box.exe и core\wintun.dll.

Требования
----------
Windows 10/11 x64. Права администратора — только для режима с tun.
